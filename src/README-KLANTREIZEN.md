# Installatie klantreizen Mijn Teamkompas

Upload deze bestanden naar de map `src` in GitHub Codespaces:

- `App.jsx`
- `KlantreisKeuze.jsx`
- `Verkennen.jsx`
- `TeamscanDigitaal.jsx`

Deze versie gaat uit van de platte structuur die nu in jouw Codespace staat:

- `src/ContactModal.jsx`
- `src/firebase.js`
- `src/email.js`
- `src/OnzeAanpak.jsx`

Na uploaden:

```bash
npm run dev
```

Test daarna:

- `/`
- `/verkennen`
- `/teamscan`
- `/onze-aanpak`

Als alles werkt:

```bash
git add .
git commit -m "Voeg twee klantreizen toe"
git push
```
